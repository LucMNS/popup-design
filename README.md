# Pop-up de confirmação

Um projeto simples de interface web que demonstra um pop-up de confirmação. Ao clicar em **Enviar**, uma mensagem aparece na tela; o botão **OK** fecha o pop-up.

## Funcionalidades

- Exibe uma mensagem de confirmação em um pop-up.
- Abre e fecha o pop-up com botões.
- Usa uma imagem de confirmação para complementar a interface.

## Tecnologias

- HTML
- CSS
- JavaScript

## 📁 Estrutura

```text
projeto05-popup/
├── img/

```

## ▶️ Como executar

1. Baixe ou clone o projeto.
2. Abra a pasta `projeto05-popup`.
3. Abra o arquivo `index.html` em um navegador.
4. Clique em **Enviar** para abrir o pop-up e em **OK** para fechá-lo.

Não é necessário instalar dependências nem iniciar um servidor.

## Observação

Este projeto é uma demonstração visual: o botão **Enviar** apenas abre o pop-up. Nenhum dado é coletado, armazenado ou enviado.
